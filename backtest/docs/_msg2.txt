Untrack the thirty-four root-level scratch files, and the two PowerShell accidents.

The root of this repository had 189 files beginning with an underscore and no
directory. Of those, thirty-two were tracked and the rest were not, which is the
shape of a rule that was added after the files were already committed: .gitignore
has said `/_*.txt`, `/_*.py`, `/_*.ps1`, `/_*.json`, `/_*.jsonl` for a long time,
and it never applied to the files that matched it, because git ignores untracked
files, not tracked ones.

What they were, having looked at every one: fifteen output logs from TypeScript
builds and server calls (_ts_out.txt, _ts_bun.txt, _cfg_test_out.txt, _ts_*), seven
API response snapshots (_api_aug27_v2.json through v5, _api_backtest.json), seven
debug and check scripts (_debug_chop_trace.py, _check_aug17.py, _rerun_sweep.py),
and three run scripts (_run_build.ps1, _run_ts.ps1, _run_ts2.ps1).

They are untracked, not deleted. The evidence in some of them is real and this
repository's own rule - that a number lives in the registry or a board doc, not
in a root-level blob - is why they should not be in history either. Anything
genuinely worth keeping belongs in backtest/tests under a name that says what it
is, which is where exp_resultsdb.py now reads results from.

Two more were committed by accident and are named for what they are: `$null`
holds a TASKKILL usage error from a `> $null` redirect that PowerShell wrote to a
file instead of discarding, and `0` is an empty file from a `> 0`. Neither matches
any pattern, so both are ignored by name.

Also removed: twenty-three _-prefixed .txt captures from this branch's own runs,
eighteen of which were zero-byte stderr files, plus five scratch scripts and JSON
dumps written while building the results database. Those were never tracked and
nothing referenced them.

After this the root has no underscore-prefixed files in git, and 130 on disk that
git is ignoring by design. The directory listing a new contributor sees is now the
project rather than the debris of the last month.
