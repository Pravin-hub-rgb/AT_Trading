## Goal
Extend backtest data from Sep 13 → Oct 24 (41 days), run top books as **forward
testing**, and verify live engine marks against TradingView for Oct 20.

## Key Principles (from user discussion)

1. **Backtest frozen at Sep 13, 2026**: Book 107's 508R result is documented and preserved.
   Results up to Sep 13 = backtest. Results from Sep 14 onward = forward test.

2. **Swing continuity**: Engine must start from **Jan 2023** (not Oct 20 cold).
   Swings carry state; a cold start from Oct 20 would produce **different** marks
   than the continuous chain. The swing engine processes candle-by-candle from the
   beginning of available data.

3. **Book independence of marks**: B1/B2/FLIP/DECISIVE marks depend only on
   `firstswing.py` (minBars=50, timeCap="00:00"). Book params affect only
   simulation/trading logic (SL, entry filters, cooldown).

4. **Same data for backtest + live**: Forward-test backtest results must use the
   same Bybit data the live engine would fetch, so marks align.
